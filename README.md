# Database Indexing and Optimization

## Project Overview
This assignment focuses on database indexing, user account management, access control, and SQL queries using MySQL.

## Learning Objectives
- Practise dropping database indexes.
- Create MySQL user accounts.
- Assign privileges to database users.
- Change user passwords.
- Understand database security and access control.
